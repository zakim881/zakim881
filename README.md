# <img src="https://raw.githubusercontent.com/umenzi/umenzi/main/wave.gif" width="30px"> Hi there

My name is **Mohammad Zaki**, an **Azure DevOps Engineer** with 5+ years of experience designing and automating enterprise CI/CD pipelines, Infrastructure as Code (IaC) with Terraform, and secure Azure cloud environments ☁️🇮🇳. Currently at **HCL Technologies** (previously at **Cognizant**), standardizing release engineering, cloud infrastructure, and zero-trust security postures for mission-critical enterprise workloads.

Previously, I obtained my **Bachelor of Engineering in Computer Science** from Rajiv Gandhi Proudyogiki Vishwavidyalaya (RGPV) 🎓.

🏗️ **Infrastructure as Code (IaC):** Deep focus on modular **Terraform**, remote state management, dynamic expressions, variables/locals, and automated drift detection.

🌐 **Azure Landing Zones & Networking:** Architecting enterprise-scale Hub-and-Spoke networks (VNets, Subnets, NSGs, Route Tables, Application Gateway, Azure Load Balancer, and Private Endpoints).

🚀 **CI/CD & GitOps:** Designing multi-stage **Azure DevOps (YAML)** and **GitHub Actions** pipelines with automated build, test, approval gates, and zero-downtime releases.

🔒 **Security Tools & DevSecOps:** Embedding automated shift-left security checks with **TFLint**, **tfsec**, and **TruffleHog**, governed by **Microsoft Entra ID (RBAC)** and **Azure Key Vault**.

📈 **Cloud Observability:** End-to-end monitoring and production diagnostics using **Azure Monitor**, **Log Analytics**, and **Application Insights**.

If you like what I do or want to collaborate, feel free to connect! 👉👈
